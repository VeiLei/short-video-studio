# 知识科普型 — 类型模板

## 适用场景

- 3 分钟讲懂一个概念
- 冷知识系列
- 原理讲解（如 Transformer、扩散模型）
- 历史/科学普及

## 黄金 3 秒钩子

用户用 0.5 秒决定是否划走。开头第一句必须制造**认知缺口**（让用户不看完不舒服）。

| 钩子类型 | 公式 | 示例 |
|---------|------|------|
| **反常识** | "其实 X 根本不是 Y" | "你以为可乐罐是圆柱形为了好拿？错了。" |
| **悬念提问** | "你有没有想过 X 怎么 Y？" | "你有没有想过，ChatGPT 是怎么理解人话的？" |
| **数字冲击** | "N% 的人都搞错了 X" | "95% 的人刷牙都刷错了，包括你。" |
| **场景冲突** | "你有没有遇到过 X？" | "凌晨三点被叫醒修服务器是什么体验？" |

> 开头第一句 ≤ 12 个字，直接进冲突。禁止"大家好我是XXX"、"今天我们来聊聊"。

## 台本结构：SCQA 框架

放弃"第一点/第二点/第三点"清单体（完播率极低），改用 SCQA：

```
S 情境（0-5s）：描述观众正在经历的具体场景
  "你花了3小时写的ppt，领导说'没亮点'"
C 冲突（5-10s）：这个场景里让人困惑/挫败的地方
  "但隔壁同事只花了20分钟，领导却说'太棒了'"
Q 疑问（10-12s）：抛出一个观众真正想知道答案的问题
  "差的到底是什么？"
A 解答（12-85s）：用生活类比解释核心原理 + 给出可操作方法
  "想象你在拼乐高——ppt就是说明书，演讲才是成品..."
```

**信息密度铁律**：
- 每 3-5 秒有新信息（新画面、新文案或新音效）
- 每 10-15 秒一个知识爆点，防止注意力流失
- 解答部分语速放慢，Q→A 之间停一拍让观众自己想

**结尾设计**（最后 5 秒，干脆利落）：
- **金句收尾**："所以，不是ppt不够好，是你没把它当乐高说明书。"
- **开放问题**："你最近一次被客户challenge是什么时候？评论区说说。"
- **可验证方法**："下次做ppt前，先对着镜子讲一遍——试试看。"
- ❌ 禁止"关注我点赞收藏"等模板引导（算法已降权）

## 角色建议

- 1 个虚拟主播（白大褂 / 休闲衬衫 + 简单背景）
- 强调"讲述"感，非"表演"感

## 节奏

- 句长控制在 15-20 字
- 关键概念用"停顿 + 强调"
- 优先低缓连贯的细微动作（缓慢抬手、微微点头），避免大幅快速动作

## Seedance 2.0 视频提示词公式

按官方公式组织每个镜头（`镜头1`、`镜头2`...）：

```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

**官方约束词（必加）**：
- `保持无字幕` 或 `避免生成任何文字或字幕`
- `不要生成Logo`
- `不要生成水印`

**分镜格式**：用 `镜头1`、`镜头2` 按事件顺序组织，不写精确时间戳。每个镜头按：运镜方式 → 主体动作与表情 → 位置或空间变化 的顺序。

**符号规范**：
- 音效用 `<>`，如 `<远处传来鸟叫声>`
- 台词用 `{}`，如 `{你有没有想过这个问题}`
- 字幕用 `【】`，如 `【Transformer 的核心秘密】`

**动作描述规则**：
- 肢体细化：缓慢抬手、微微低头、手指轻敲桌面
- 情绪外化：不说"很紧张"，说"频繁看手表、手指不停敲击桌面、呼吸急促"
- 优先低缓小动作，规避狂奔、大跳、剧烈翻滚

**运镜**：一个镜头只一种运镜方式（中景、特写、全景、缓慢推镜、平稳横移、固定镜头）。

**角色锚点模板**（从 设定/角色.md 原样锁定）：

```markdown
### 角色锚点（不可变）
- **发型/发色**：黑色短发，偏分
- **脸型特征**：方脸、浓眉、无眼镜
- **标志配饰**：银色领针
- **体型/身高**：瘦高、178cm左右
- **着装基底**：白大褂 + 深灰衬衫
```

**shot 提示词示例（知识科普型）**：

```
镜头1：中景，缓慢推镜，黑色短发偏分方脸浓眉的男研究员穿着白大褂深灰衬衫，
面对镜头微微点头，双手自然放在讲台上，实验室背景。
柔和晨窗光，半写实CG渲染，低饱和清新色调。
高清电影质感，保持无字幕，不要生成Logo，不要生成水印。
```
