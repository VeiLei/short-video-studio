# 知识科普型 — 类型模板

## 适用场景

- 3 分钟 / 5 分钟讲懂一个概念
- 冷知识系列
- 原理讲解（如 Transformer、扩散模型）
- 历史/科学普及

## 钩子策略（视频前 3 秒）

- **悬念型**："你有没有想过，X 是怎么 Y 的？"
- **反常识型**："其实 X 根本不是 Z 做的。"
- **数字冲击**："90% 的人都搞错了 X。"

## 推荐结构

```
[0-3s]  钩子：提出悬念
[3-10s] 引入：场景化铺垫
[10-30s] 核心 1：第一层解释
[30-50s] 核心 2：类比 + 可视化
[50-70s] 核心 3：深入一层
[70-85s] 总结：回到开头的钩子
[85-90s] CTA：点赞 + 关注
```

## 角色建议

- 1 个虚拟主播（白大褂 / 休闲衬衫 + 简单背景）
- 无需复杂场景
- 强调"讲述"感，非"表演"感

## 节奏

- 句长控制在 15-20 字
- 长句拆成 2-3 个镜头
- 关键概念用"停顿 + 强调"

## Seedance 2.0 五层 Prompt 模板

每个 shot 的 prompt 必须使用以下填空式结构（60 词以内）：

```
主体: [{角色锚点词原样锁定}] + [{着装}]
动作: [一个动词短语，现在时]
镜头: [景别: 广角/中景/近景/特写] + [运动: 缓慢推入/稳定器跟拍/锁定] + [角度: 眼平/略俯/略仰]，[焦距: 35mm感/85mm感]
风格: [半写实CG渲染/3D渲染写实]，[布光: 柔和晨窗光/工作室柔光]，[色调: 低饱和清新/冷暖混合]
约束: 无跳跃变焦，无额外角色，无文字叠加，保持角色特征一致，画面连贯流畅
```

**shot 级提示词示例（知识科普型）**：

```
主体: 黑色短发齐刘海，圆脸左颊小痣，细框眼镜，白大褂浅蓝衬衫，中等身材。
动作: 面对镜头微微点头，双手自然放在讲台上。
镜头: 中景，缓慢推入，眼平高度，35mm感。
风格: 半写实CG渲染，工作室柔光，低饱和清新色调。
约束: 无跳跃变焦，无额外角色，保持角色特征一致，画面连贯流畅。
```

## 角色锚点模板（知识科普型）

```markdown
### 角色锚点（不可变）
- **发型/发色**：黑色短发，偏分
- **脸型特征**：方脸、浓眉、无眼镜
- **标志配饰**：银色领针
- **体型/身高**：瘦高、178cm左右
- **着装基底**：白大褂 + 深灰衬衫
```
