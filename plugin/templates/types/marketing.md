# 营销种草型 — 类型模板

## 适用场景

- 产品测评
- 购物推荐 / 带货
- 生活方式分享
- 网红/达人种草

## 钩子策略（视频前 3 秒）

- **强冲击**："这款 XX 真的太顶了！"
- **痛点共鸣**："每次 X 都让我崩溃，直到我发现..."
- **价格锚定**："9.9 居然能买到这种东西？！"

## 推荐结构

```
[0-3s]  钩子：痛点 / 惊喜 / 反转
[3-15s] 问题：用户场景化描述
[15-30s] 产品出场：第一印象
[30-50s] 卖点 1：核心功能
[50-65s] 卖点 2：差异化优势
[65-80s] 卖点 3：使用场景
[80-90s] CTA：购买链接 / 优惠码
```

## 角色建议

- 出镜达人（真实感强）
- 产品特写镜头（细节质感）
- 多场景（试用 / 对比 / 上身效果）

## 节奏

- 情绪起伏明显
- 关键卖点处放慢 + 重音
- 优先低缓连贯的展示动作（缓慢旋转产品、轻微推近特写），避免大幅快速动作

## Seedance 2.0 视频提示词公式

按官方公式组织每个镜头（`镜头1`、`镜头2`...）：

```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

**官方约束词（必加）**：
- `保持无字幕` 或 `避免生成任何文字或字幕`
- `不要生成Logo`
- `不要生成水印`

**分镜格式**：用 `镜头1`、`镜头2` 按事件顺序组织。每个镜头按：运镜方式 → 主体动作与表情 → 位置或空间变化 的顺序。

**符号规范**：
- 音效用 `<>`
- 台词用 `{}`
- 字幕用 `【】`

**动作描述规则**：
- 肢体细化 + 程度量化：轻握杯身、缓慢旋转展示、手指轻划过产品表面
- 情绪外化：不说"很惊喜"，说"嘴角上扬、眼睛睁大、双手捧起产品"
- 优先低缓连贯展示动作

**运镜**：一个镜头只一种运镜方式。产品特写用缓慢推镜，场景展示用平稳横移，达人出镜用固定镜头或轻微手持跟拍。

**角色锚点模板**（营销种草型，从 设定/角色.md 原样锁定）：

```markdown
### 角色锚点（不可变）
- **发型/发色**：棕色长卷发，披肩
- **脸型特征**：鹅蛋脸、右眉尾小疤、淡妆
- **标志配饰**：银色细链项链
- **体型/身高**：匀称、165cm左右
- **着装基底**：米白亚麻衬衫 + 牛仔裤
```

**shot 提示词示例（营销种草型）**：

```
镜头1：中近景，平稳横移，棕色长卷发鹅蛋脸的达人站在咖啡吧台后，
双手捧起哑光白陶瓷马克杯，对着镜头微笑展示产品，暖调居家场景。
柔和晨窗光，写实生活化风格，暖调高级感。
高清细节丰富，保持无字幕，不要生成Logo，不要生成水印。
```

## 标题公式

- "[数字]+[情绪]+[产品/品类]"
- "3 个理由让我离不开这款咖啡"
- "9.9 买到的高级感"
- "姐妹们冲！这款 XX 真的不踩雷"
