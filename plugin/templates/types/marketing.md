# 营销种草型 — 类型模板

## 适用场景

- 产品测评
- 购物推荐 / 带货
- 生活方式分享
- 网红/达人种草

## 钩子策略（视频前 3 秒）

- **强冲击**："这款 XX 真的太顶了！"
- **痛点共鸣**："每次 X 都让我崩溃，直到我发现..."
- **价格锚定**："9.9 居然能买到这种东西？！"

## 推荐结构

```
[0-3s]  钩子：痛点 / 惊喜 / 反转
[3-15s] 问题：用户场景化描述
[15-30s] 产品出场：第一印象
[30-50s] 卖点 1：核心功能
[50-65s] 卖点 2：差异化优势
[65-80s] 卖点 3：使用场景
[80-90s] CTA：购买链接 / 优惠码
```

## 角色建议

- 出镜达人（真实感强）
- 产品特写镜头（细节质感）
- 多场景（试用 / 对比 / 上身效果）

## 节奏

- 情绪起伏明显
- 关键卖点处放慢 + 重音
- BGM 节奏匹配情绪

## Seedance 2.0 五层 Prompt 模板

每个 shot 的 prompt 必须使用以下填空式结构（60 词以内）：

```
主体: [{角色锚点词原样锁定}] + [{着装/产品}]
动作: [一个动词短语，现在时]
镜头: [景别] + [运动: 稳定器跟拍/缓慢推轨/手持微晃] + [角度]，[焦距感]
风格: [写实生活化/3D渲染产品质感]，[布光: 自然窗光/暖色室内光]，[色调: 暖调高级感/清新明亮]
约束: 无跳跃变焦，无Logo，无文字叠加，保持角色/产品特征一致，画面连贯流畅
```

**shot 级提示词示例（营销种草型）**：

```
主体: 30多岁陶瓷马克杯，哑光白，简约设计。
动作: 蒸汽升腾，一只手将杯子滑入画面，缓缓停下。
镜头: 中近景，缓慢推轨，眼平高度，标准镜头感。
风格: 写实生活化，柔和晨窗光，暖调高级感。
约束: 无Logo，无跳跃变焦，保持产品特征一致，画面连贯流畅。
```

## 角色锚点模板（营销种草型）

```markdown
### 角色锚点（不可变）
- **发型/发色**：棕色长卷发，披肩
- **脸型特征**：鹅蛋脸、右眉尾小疤、淡妆
- **标志配饰**：银色细链项链
- **体型/身高**：匀称、165cm左右
- **着装基底**：米白亚麻衬衫 + 牛仔裤
```

## 标题公式

- "[数字]+[情绪]+[产品/品类]"
- "3 个理由让我离不开这款咖啡"
- "9.9 买到的高级感"
- "姐妹们冲！这款 XX 真的不踩雷"
