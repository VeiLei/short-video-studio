# 故事段子型 — 类型模板

## 适用场景

- 反转小故事
- 日常 vlog
- 段子 / 搞笑
- 情感共鸣短片

## 钩子策略（视频前 3 秒）

- **场景开局**："昨天下午三点，我在咖啡厅遇到..."
- **悬念型**："我到现在都没想明白那天到底发生了什么。"
- **冲突型**："我爸突然说：'我们搬家吧。'"

## 推荐结构

```
[0-3s]  钩子：场景/冲突/悬念
[3-20s] 铺垫：背景/人物/情绪
[20-40s] 发展：第一个转折
[40-65s] 高潮：核心冲突
[65-80s] 反转：意外结局
[80-90s] 余味：情绪留白
```

## 角色建议

- 1-2 个角色（无需多，官方建议不超过 4 人）
- 真实生活场景（家、咖啡厅、办公室、街道）
- 强调表演和情绪，非旁白

## 节奏

- 镜头切换按事件节奏推进
- 关键情绪点用近景/特写 + 缓慢推镜
- 结尾留白 > 总结
- 优先低缓连贯的细微动作表现情绪

## Seedance 2.0 视频提示词公式

按官方公式组织每个镜头（`镜头1`、`镜头2`...）：

```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

**官方约束词（必加）**：
- `保持无字幕` 或 `避免生成任何文字或字幕`
- `不要生成Logo`
- `不要生成水印`

**分镜格式**：用 `镜头1`、`镜头2` 按事件发生顺序组织。每个镜头按：运镜方式 → 主体动作与表情 → 位置或空间变化 的顺序。

**符号规范**：
- 音效用 `<>`，如 `<远处传来狗叫声>`
- 台词用 `{}`，如 `{你怎么现在才来}`
- 字幕用 `【】`

**动作描述规则**：
- 肢体细化 + 程度量化：缓慢推开玻璃门、手指攥紧衣角、肩膀微微颤抖、眼眶泛红
- 情绪外化（关键！）：

| 情绪 | 外化为动作 |
|------|-----------|
| 悲伤 | 低头、肩膀微颤、眼眶泛红、手指攥紧衣角 |
| 喜悦 | 嘴角上扬、眉眼舒展、脚步轻快 |
| 紧张 | 频繁看手表、手指敲击桌面、呼吸急促、眼神闪躲 |
| 愤怒 | 双拳紧握、下颌紧绷、胸口起伏 |
| 释然 | 长舒一口气、肩膀放松、露出淡淡微笑 |

**运镜**：一个镜头只一种运镜方式。对白场景用固定镜头 + 缓慢切换半身特写，追逐/冲突用手持轻微晃动，情绪转折用缓慢推镜到近景。

**角色锚点模板**（故事段子型，从 设定/角色.md 原样锁定）：

```markdown
### 角色锚点（不可变）
- **发型/发色**：黑色碎短发，微乱
- **脸型特征**：方脸、络腮胡渣、左眉尾小疤
- **标志配饰**：黑色皮质手环
- **体型/身高**：健壮、175cm左右
- **着装基底**：深灰卫衣 + 黑色长裤
```

**shot 提示词示例（故事段子型）**：

```
镜头1：中景，手持轻微晃动跟拍，黑色碎短发方脸胡渣的男人推开咖啡厅玻璃门，
抬头扫视店内，目光停在角落座位，脚步放慢。
阴天散射光透过落地窗，写实纪实风格，微冷电影感色调。
高清电影质感，保持无字幕，不要生成Logo，不要生成水印。
```

## 标题公式

- "[场景]+[情绪]+[动作]"
- "咖啡厅里，我遇到了 5 年没见的她"
- "凌晨 3 点，我爸敲开了我的门"
- "那条朋友圈发出去 5 分钟后，我后悔了"
