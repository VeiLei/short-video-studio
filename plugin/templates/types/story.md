# 故事段子型 — 类型模板

## 适用场景

- 反转小故事
- 日常 vlog
- 段子 / 搞笑
- 情感共鸣短片

## 黄金 3 秒钩子

故事型视频的核心钩子不是"提出问题"，而是**直接把人扔进场景**。

| 钩子类型 | 公式 | 示例 |
|---------|------|------|
| **场景开局** | "X 时间，我在 X 地方，遇到 X" | "昨天下午三点，咖啡厅里，我遇到了 5 年没见的她。" |
| **悬念前置** | "我到现在都没想明白 X" | "我到现在都没想明白那天到底发生了什么。" |
| **冲突开局** | "XX 突然说：'X'" | "我爸突然说：我们搬家吧。就现在。" |
| **结果前置** | 先展示最震撼的结果/反转画面 | "这张照片发出去 5 分钟后，我后悔了。" |

> 第一句就是故事的第一帧。不说"大家好今天讲一个故事"——直接演。

## 台本结构：三幕微剧

```
第一幕 钩子（0-5s）：直接进入场景/冲突
  "凌晨 3 点，我爸敲开我的房门，手里拿着一个信封。"
第二幕 推进（5-75s）：按时间线展开
  - 铺垫（5-15s）：背景/人物状态
  - 转折1（15-35s）：第一个意外
  - 高潮（35-60s）：冲突顶点（情绪最强处放慢）
  - 转折2（60-75s）：反转/意外结局
第三幕 余味（75-85s）：情绪留白，不总结
  "他把信封放桌上就走了。我打开，里面是 20 年前他写给我妈的信。"
```

**情绪节奏**：
- 平淡→紧张→爆发→余味，每次情绪转换配运镜变化
- 高潮前留 1-2 秒空镜蓄力（如手停住、雨滴落下、门把手特写）
- 结尾留白，让观众自己消化，不解释"这说明了什么"

**关键约束**：
- 每 3-5 秒有新的叙事信息推进
- 情绪用身体细节（手指颤抖、眼眶泛红），不用旁白解释（"他很伤心"）
- 对话用 `{}` 标记，Seedance 原生生成口型同步
- 禁止"这个故事告诉我们"、"希望大家能明白"

## 角色建议

- 1-2 个角色（无需多，官方建议不超过 4 人）
- 真实生活场景（家、咖啡厅、办公室、街道）
- 强调表演和情绪，非旁白

## 节奏

- 镜头切换按事件节奏推进
- 关键情绪点用近景/特写 + 缓慢推镜
- 结尾留白 > 总结
- 优先低缓连贯的细微动作表现情绪

## Seedance 2.0 视频提示词公式

按官方公式组织每个镜头（`镜头1`、`镜头2`...）：

```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

**官方约束词（必加）**：
- `保持无字幕` 或 `避免生成任何文字或字幕`
- `不要生成Logo`
- `不要生成水印`

**分镜格式**：用 `镜头1`、`镜头2` 按事件发生顺序组织。每个镜头按：运镜方式 → 主体动作与表情 → 位置或空间变化 的顺序。

**符号规范**：
- 音效用 `<>`，如 `<远处传来狗叫声>`
- 台词用 `{}`，如 `{你怎么现在才来}`
- 字幕用 `【】`

**动作描述规则**：
- 肢体细化 + 程度量化：缓慢推开玻璃门、手指攥紧衣角、肩膀微微颤抖、眼眶泛红
- 情绪外化（关键！）：

| 情绪 | 外化为动作 |
|------|-----------|
| 悲伤 | 低头、肩膀微颤、眼眶泛红、手指攥紧衣角 |
| 喜悦 | 嘴角上扬、眉眼舒展、脚步轻快 |
| 紧张 | 频繁看手表、手指敲击桌面、呼吸急促、眼神闪躲 |
| 愤怒 | 双拳紧握、下颌紧绷、胸口起伏 |
| 释然 | 长舒一口气、肩膀放松、露出淡淡微笑 |

**运镜**：一个镜头只一种运镜方式。对白场景用固定镜头 + 缓慢切换半身特写，追逐/冲突用手持轻微晃动，情绪转折用缓慢推镜到近景。

**角色锚点模板**（故事段子型，从 设定/角色.md 原样锁定）：

```markdown
### 角色锚点（不可变）
- **发型/发色**：黑色碎短发，微乱
- **脸型特征**：方脸、络腮胡渣、左眉尾小疤
- **标志配饰**：黑色皮质手环
- **体型/身高**：健壮、175cm左右
- **着装基底**：深灰卫衣 + 黑色长裤
```

**shot 提示词示例（故事段子型）**：

```
镜头1：中景，手持轻微晃动跟拍，黑色碎短发方脸胡渣的男人推开咖啡厅玻璃门，
抬头扫视店内，目光停在角落座位，脚步放慢。
阴天散射光透过落地窗，写实纪实风格，微冷电影感色调。
高清电影质感，保持无字幕，不要生成Logo，不要生成水印。
```

## 标题公式

- "[场景]+[情绪]+[动作]"
- "咖啡厅里，我遇到了 5 年没见的她"
- "凌晨 3 点，我爸敲开了我的门"
- "那条朋友圈发出去 5 分钟后，我后悔了"
