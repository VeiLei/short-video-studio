# 故事段子型 — 类型模板

## 适用场景

- 反转小故事
- 日常 vlog
- 段子 / 搞笑
- 情感共鸣短片

## 钩子策略（视频前 3 秒）

- **场景开局**："昨天下午三点，我在咖啡厅遇到..."
- **悬念型**："我到现在都没想明白那天到底发生了什么。"
- **冲突型**："我爸突然说：'我们搬家吧。'"

## 推荐结构

```
[0-3s]  钩子：场景/冲突/悬念
[3-20s] 铺垫：背景/人物/情绪
[20-40s] 发展：第一个转折
[40-65s] 高潮：核心冲突
[65-80s] 反转：意外结局
[80-90s] 余味：情绪留白
```

## 角色建议

- 1-2 个角色（无需多）
- 真实生活场景（家、咖啡厅、办公室、街道）
- 强调表演和情绪，非旁白

## 节奏

- 镜头切换频繁（每 3-5s 一切）
- 关键情绪点用慢动作
- 结尾留白 > 总结

## Seedance 2.0 五层 Prompt 模板

每个 shot 的 prompt 必须使用以下填空式结构（60 词以内）：

```
主体: [{角色锚点词原样锁定}] + [{着装}]
动作: [一个动词短语，现在时]
镜头: [景别] + [运动: 手持微晃/缓慢推入/锁定] + [角度]，[焦距感: 35mm纪实感/85mm情绪感]
风格: [写实纪实/电影感]，[布光: 现场自然光/昏黄台灯光/阴天散射光]，[色调: 微冷纪实感/暖调怀旧]
约束: 无跳跃变焦，无额外角色，无镜头光晕，保持角色特征一致，画面连贯流畅
```

**shot 级提示词示例（故事段子型）**：

```
主体: 黑色碎短发，方脸胡渣，左眉尾疤，深灰卫衣，中等身材。
动作: 推开咖啡厅玻璃门，抬头扫视店内，目光停在角落座位。
镜头: 中景，手持微晃，跟拍入店，35mm纪实感。
风格: 写实纪实风，阴天散射光，微冷纪实色调。
约束: 无跳跃变焦，无镜头光晕，保持角色特征一致，画面连贯流畅。
```

## 角色锚点模板（故事段子型）

```markdown
### 角色锚点（不可变）
- **发型/发色**：黑色碎短发，微乱
- **脸型特征**：方脸、络腮胡渣、左眉尾小疤
- **标志配饰**：黑色皮质手环
- **体型/身高**：健壮、175cm左右
- **着装基底**：深灰卫衣 + 黑色长裤
```

## 标题公式

- "[场景]+[情绪]+[动作]"
- "咖啡厅里，我遇到了 5 年没见的她"
- "凌晨 3 点，我爸敲开了我的门"
- "那条朋友圈发出去 5 分钟后，我后悔了"
